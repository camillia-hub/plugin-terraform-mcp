# Terraform MCP

Works with Terraform and the registry. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/terraform-mcp-server

Installs from the Camillia hub as `terraform-mcp-a6996f`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
